<h2 id="install">インストール</h2>

```sh
cargo install ayame-spell
ayame-spell
ayame-spell fix
```

最初のコマンドで CLI と LSP サーバーの両方が入ります。リリースバイナリと
プロジェクト設定は[はじめに](./getting-started/)を参照してください。

<h2 id="quick-start">クイックスタート</h2>

```sh
ayame-spell init
ayame-spell dict add en-base python
ayame-spell words collect
ayame-spell words triage
```

修正表モードは設定なしで動きます。未知語も検出したい場所では `en-base` を
追加し、対象パスを辞書モードへ切り替えます。

<h2 id="comparison">ほかの方式との違い</h2>

| 方式 | 誤検出 | 未知のスペルミス | 共有辞書 | 日本語 |
| --- | --- | --- | --- | --- |
| 修正表方式（typos、codespell） | 非常に少ない | 見逃す | 通常なし | 非対応 |
| 辞書方式（cSpell、Harper） | 調整が必要 | 検出 | あり | 限定的 |
| ayame-spell | パスごとに選択 | パスごとに選択 | あり | 標準対応 |

静かな CI の基準には修正表モード、網羅性が必要な場所には辞書モードを使います。
`[[overrides]]` により、一つのプロジェクト内で両方を併用できます。
