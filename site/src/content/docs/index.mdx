<h2 id="install">Install</h2>

```sh
cargo install ayame-spell
ayame-spell
ayame-spell fix
```

The first command installs both the CLI and the LSP server. See
[Getting started](./getting-started/) for release binaries and project setup.

<h2 id="quick-start">Quick start</h2>

```sh
ayame-spell init
ayame-spell dict add en-base python
ayame-spell words collect
ayame-spell words triage
```

Corrections mode works with no configuration. Add `en-base` and switch selected
paths to dictionary mode when you want unknown-word detection.

<h2 id="comparison">How it compares</h2>

| Approach | False positives | Unknown typos | Shared dictionaries | Japanese |
| --- | --- | --- | --- | --- |
| Corrections tables (typos, codespell) | Very low | Missed | Usually no | No |
| Dictionaries (cSpell, Harper) | Needs tuning | Found | Yes | Limited |
| ayame-spell | Selectable by path | Selectable by path | Yes | First-class |

Use corrections mode for a quiet CI baseline and dictionary mode where
completeness matters. Both modes can coexist through `[[overrides]]`.
