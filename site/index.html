Fast, low-noise spell checker for code and prose — English & Japanese.
コードと文章のための高速・低ノイズなスペルチェッカー。既知タイポ修正・共有辞書・表記ゆれ検出。

GitHub Docs Dictionary Registry

Why ayame-spell なぜ作ったか

🎯 Low noise by default

既知のスペルミスだけを指摘する corrections モードが既定。Kadane や heapq に赤線は出ません。

📚 Shared dictionaries

プロジェクト辞書 (ayame-words.txt) は git で共有、グローバル辞書は全プロジェクト共通。レジストリから dict add 一発。

🗾 Japanese aware

表記ゆれ (サーバ/サーバー) を文書内一貫性でノイズなく検出。全角英数・半角カナ・全角スペースも。

⚡ Fast on huge files

Rust製。35MB / 40万行のテキストを約1.3秒・56MB RSS で全行チェック。黙って途中で打ち切りません。

🧹 Bulk workflows

words collect で未知語を頻度順に一括収集、words triage で複数選択して辞書へ/ignoreへ一括処理。

🔌 CLI + LSP + VS Code

1つの設定ファイルで CI (CLI) とエディタ (LSP/VS Code) が同じ結果に。設定はホットリロード。

Install インストール

# CLI + LSP server
cargo install ayame-spell

# check the current directory (corrections mode, zero config)
ayame-spell

# apply safe fixes
ayame-spell fix

Quick start プロジェクト設定

ayame-spell init                      # write ayame-spell.toml
ayame-spell dict add en-base python   # enable dictionary mode wordlists
ayame-spell words collect             # list unknown words by frequency
ayame-spell words triage              # bulk-select → project/global dict or ignore

Dictionary registry 共有辞書レジストリ

Wordlists and variant rules are served from this site and verified by sha256. ayame-spell dict add <name> がダウンロードと設定追記まで行います。

How it compares 設計方針

typos の「既知タイポのみ・誤検出ほぼゼロ」哲学と、 cSpell の「共有辞書エコシステム」、 textlint/prh の「表記ゆれルール」を1つの高速な Rust バイナリに統合したのが ayame-spell です。 CI では corrections モード、エディタでは dictionary モード + 一括トリアージ、という使い分けが1つの設定ファイルで完結します。
