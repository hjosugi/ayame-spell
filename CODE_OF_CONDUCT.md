# Code of Conduct

## Our standard

ayame-spell welcomes people of every background and experience level. Be
respectful, assume good intent while discussing ideas, and make technical
feedback specific and actionable. Maintainers and contributors should help
newcomers participate without requiring unwritten project knowledge.

Examples of welcome behavior include:

- discussing code and decisions rather than attacking people;
- accepting corrections and giving others room to learn;
- respecting names, pronouns, privacy, and personal boundaries;
- disclosing conflicts of interest; and
- prioritizing community safety when resolving a disagreement.

Harassment, discrimination, threats, stalking, sexualized attention, deliberate
intimidation, sustained disruption, doxxing, or publishing private information
without permission are unacceptable.

## Scope and enforcement

This standard applies in repository issues, pull requests, reviews, discussions,
and project-related public or private communication. Maintainers may edit or
remove content, lock a conversation, reject a contribution, or temporarily or
permanently restrict participation. Enforcement decisions should consider
context, impact, repeated behavior, and the safety of affected people.

Report conduct concerns to the repository owner through a private contact method
listed on their GitHub profile. Do not publish sensitive evidence in an issue.
If no private contact is listed, open an issue containing no sensitive details
and ask the maintainer to establish a private reporting channel.
For threats or abuse occurring on GitHub, also use GitHub's abuse-reporting
tools. Reports will be handled as privately as the available channel permits,
and retaliation against a reporter is prohibited.

## 日本語

ayame-spell は背景や経験を問わず参加を歓迎します。相手を尊重し、善意を前提に
議論し、技術的なフィードバックは具体的で実行可能な形にしてください。名前、
代名詞、プライバシー、個人の境界を尊重し、初心者に暗黙知を要求しません。

嫌がらせ、差別、脅迫、ストーキング、性的な注目、意図的な威圧、継続的な妨害、
doxxing、許可のない個人情報の公開は禁止します。この規範は issue、pull
request、review、discussion、およびプロジェクトに関係する公開・非公開の連絡に
適用されます。

問題は GitHub profile に記載された非公開の連絡手段でリポジトリ所有者へ報告し、
機微な証拠を public issue に投稿しないでください。GitHub 上の脅迫や abuse は
GitHub の報告機能も利用してください。非公開の連絡先がない場合は、機微な情報を
含めずに issue で非公開の報告手段を依頼してください。報復は禁止し、利用できる
連絡手段の範囲で報告を非公開に扱います。
